# MOOS - Modern OS

A macOS-inspired web operating system built with Next.js.

## Quick Start

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Features

- macOS-like UI (menu bar, dock, draggable windows)
- Desktop with icons and wallpaper
- Apps: Calculator, Calendar, To-Do, Spreadsheet, PDF
- Login system
- Window management

## Deploy to Vercel

1. Connect GitHub repo to Vercel
2. Auto-detects Next.js
3. Deploy!

## Tech Stack

- Next.js 14
- React 18
- TypeScript
- Zustand (state)
